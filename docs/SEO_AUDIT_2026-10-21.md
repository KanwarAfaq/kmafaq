# SEO, indexing, GEO and AEO audit — 21 October 2026

Production site: https://kmafaq.site

## Scope and preservation

Reviewed repository routing, robots.txt, sitemaps, canonical URLs, initial HTML, metadata, structured data, index/noindex handling, and build failure behavior. Live checks covered robots, XML structure, unknown paths, and representative landing/detail pages. This is not a claim that every page is indexed or that every backlink has been inspected. Existing published slugs and article content were preserved. No mass deletion, keyword rewrite, synthetic reviews, or paid backlinks were introduced.

## Findings and changes

- Public blog URLs initially returned homepage metadata, including a homepage canonical. Added a public server HTML response with the article’s existing title, excerpt, content, canonical, share tags, and BlogPosting schema. The React application still loads normally.
- Missing articles return HTTP 404; data outages return 503 with no-store instead of misclassifying published articles as missing.
- The sitemap previously silently shrank to static routes on database errors and stopped at the default API row limit. Added pagination, a bounded timeout, a targeted legacy updated_at-column fallback, and 503/no-store on incomplete results.
- Removed the unconditional sitemap cache header from Vercel configuration so errors honor the handler’s no-store policy. Existing slugs and stored content were not changed.

## Verification

npm test (4 cases covering metadata/XSS escaping, pagination, outage handling, and 404); npm run build (9 static routes plus server-rendered blog route).

Live robots.txt and sitemap.xml were publicly reachable during the audit. The sitemap contained approximately 12 page URLs (a snapshot, not an indexed-page count). The robots file advertises `https://kmafaq.site/sitemap.xml`. A live fetch demonstrates public reachability, not proof of Googlebot ingestion. Vercel must deploy this commit before the code changes affect production.

## Search Console and remaining external actions

All five domain properties were discoverable in the connected Search Console account. Windsor refused real sitemap and search-performance data because eight properties are connected on a free plan limited to one account; its placeholder zero values were excluded from this audit. No sitemap-submission write action is exposed by that connector. Actual indexing coverage, Google-selected canonicals, crawl dates, impressions, clicks, ranking changes, manual actions, and Links reports therefore remain unverified.

After deployment, inspect the canonical homepage and one existing detail URL in Search Console; confirm the submitted sitemap is the URL above and its status is Success. Export Page Indexing, Sitemaps, Performance and Links reports (or restore connector reads) for a complete Google-side assessment. Do not remove existing indexed URLs or resubmit hundreds of pages blindly.

## Content, GEO/AEO, off-page SEO, and performance

- Clear headings, crawlable original content, consistent author/publisher identity, and truthful structured data help search and answer systems understand pages. These repairs target accessibility and correctness, not guaranteed inclusion in AI answers.
- Existing indexed copy was not bulk-rewritten to remove perceived filler. Content cleanup requires evidence about indexed pages and editorial review, especially generated factual claims and citations.
- Off-page work remains an evidence-based follow-up: use the GSC Links report to inspect referring domains, keep owned profiles consistent, and earn relevant editorial references. No fabricated authority scores, link purchases, or unsolicited outreach were performed.
- Build output was checked, but a build is not a Core Web Vitals measurement. Field LCP/INP/CLS and mobile performance need CrUX/GSC data; large bundle warnings remain a separate optimization opportunity where present.
- Indexing and ranking remain Google’s decision. These fixes remove technical obstacles; they do not guarantee a position, traffic increase, or indexing date.
